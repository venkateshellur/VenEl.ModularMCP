# VenEl.ModularMCP Plugin Module

⚠️ **Notice:** This package is **not** an independent, standalone library.

This is a dynamically-loaded plugin module (a "Spoke") designed exclusively for the **VenEl.ModularMCP** runtime engine (the "Hub"). It acts as a lightweight wrapper that wires up underlying Model Context Protocol (MCP) tool integrations into the main host server.

### What is VenEl.ModularMCP?
VenEl.ModularMCP is a highly extensible Model Context Protocol host engine. Instead of a monolithic server, it allows developers to dynamically install only the specific integrations they need at runtime.

For more information, please visit the main GitHub repository:
https://github.com/venkateshellur/VenEl.ModularMCP
